# 🌦️ Flutter Weather App

A lightweight and responsive Flutter application that allows users to fetch current weather information and a 3-day forecast for any city by entering its name. The app is built following the MVC architectural pattern and utilizes Cubit for state management. It integrates with the WeatherAPI to retrieve weather data. Due to the limitations of the free API tier, the forecast is currently limited to 3 days.

## 📍 Additional Feature

The app uses the `google_maps_flutter` package to display the searched city's location on a map, enhancing the overall experience with geographic context.

---

## 🚀 Features

- **City-Based Weather Search:** Enter any city name to retrieve its current weather and a 3-day forecast.
- **City Location on Map:** Displays the searched city’s position on an interactive Google Map.
- **MVC Architecture:** Structured using the Model-View-Controller pattern for organized and maintainable code.
- **State Management with Cubit:** Efficient and reactive state handling using Cubit from the Bloc library.
- **HTTP Integration:** Fetches data from WeatherAPI using the `http` package.
- **Lottie Animations:** Enhances user experience with smooth and visually appealing animations.
- **Responsive Design:** Ensures optimal display across various device sizes and orientations.

---

## 🛠️ Technologies Used

- **Flutter:** UI toolkit for building natively compiled applications.
- **Dart:** Programming language optimized for building mobile, desktop, server, and web applications.
- **Cubit (Bloc Library):** Lightweight state management solution.
- **HTTP:** For making HTTP requests to fetch weather data.
- **Lottie:** For rendering animations.
- **Responsive Framework:** To make the UI adaptable to different screen sizes.
- **Google Maps Flutter:** To display the geographic location of the searched city.
